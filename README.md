# Sales Prediction Using Machine Learning

A simple Machine Learning project that predicts future sales using historical sales data. This project helps businesses improve planning, inventory management, and decision-making.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Features
- Data preprocessing
- Sales prediction using ML
- Model training and evaluation
- Data visualization

```bash
git clone https://github.com/your-username/sales-prediction-ml.git

Usage

python predict.py
